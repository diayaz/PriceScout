# PriceScout

Price-comparison website: one product, four stores (Amazon, Pinduoduo, Poizon, Official Site) — find where it is cheapest.

**Live website:** https://diayaz.github.io/PriceScout/
**Team (SE-2502):** Dias Zhumakhan, Agzam Duysenov

## Pages
index · products · stores · about · contact · market (Live Market, DummyJSON API) · signup · login · profile

## Features
- Responsive layout (Bootstrap 5, Flexbox, Grid)
- Day / Night theme saved in localStorage
- Sign Up / Log In / Profile simulated with localStorage
- JavaScript form validation (email, password, required fields, phone)
- Search and filters with saved results
- External API: DummyJSON Products (fetch + async/await, loading and error states)
- Hover effects and smooth animations
